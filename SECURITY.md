# Security policy

## Supported versions

Seamerge is in its first release line. Only the latest release receives security fixes.

| Version | Supported |
|---|---|
| 0.1.x | yes |

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately with GitHub's "Report a vulnerability" option, on the Security tab of the repository.

Include the version of Seamerge, the macOS version, and the steps that reproduce the problem. Seamerge handles the files you give it and the Git configuration of your user account, so reports about either are especially welcome.

We aim to acknowledge a report within a week and will tell you when a fix is released.
